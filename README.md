# Слежка Авито

Локальный сервис: ссылка поиска Авито становится слежкой. Первый успешный ответ запоминается молча, дальше в ленту попадают только новые объявления и смена цены. Пульт открывается в браузере. Если задан токен, те же события уходят в Telegram.

С этой машины Авито (Qrator) отвечает `429`. Сервис на таком ответе ставит слежку на паузу и увеличивает интервал до 30 минут. Капчу и ограничения он не обходит.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
cp .env.example .env
.venv/bin/python -m app
```

Пульт: http://127.0.0.1:8080

В `.env` можно вписать `BOT_TOKEN` от BotFather. Без токена лента остаётся на странице пульта.

Кнопки «Снимок примера» и «Новые в примере» прогоняют сохранённую выдачу и не ходят в Авито. «Проверить Авито один раз» делает один запрос по ссылке.

Проверки:

```bash
.venv/bin/pytest
```

Один живой запрос, без постановки на повтор:

```bash
.venv/bin/python -m app.once 'https://www.avito.ru/moskva/telefony?q=iphone'
```

## Что хранится

С карточки в выдаче: id, заголовок, цена, город, дата, фото, ссылка. Телефон продавца не запрашивается.

Минимальный интервал опроса — 45 секунд. Между любыми живыми запросами есть пауза (`REQUEST_GAP_SECONDS`, по умолчанию 2).

## Позже, на VPS

`docker-compose.yml` поднимает Postgres и тот же процесс. Пароль в файле учебный, перед настоящим сервером его нужно сменить. На VPS имеет смысл `ALLOW_FIXTURE_POLL=0`. Для бота в окружение кладётся `BOT_TOKEN`.
